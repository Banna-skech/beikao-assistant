# 模拟面试工具 — Mock Interview

## 使用说明

当用户说"模拟面试"时，按照以下流程进行完整的模拟训练。

---

## 模式选择

首先询问用户想练习哪种模式：

| 模式 | 时长 | 适合场景 |
|------|------|----------|
| **快速模式** | 3-5题/10分钟 | 碎片化练习 |
| **标准模式** | 8-10题/20分钟 | 完整模拟 |
| **群面模式** | 1题/30分钟 | 无领导小组讨论模拟 |

---

## 模式1：半结构化面试（快速模式）

### 流程：
1. 面试官开场白
2. 依次提问3-5个高频问题
3. 每个问题用户回答后给出点评（优点+改进建议）
4. 全部结束后给出总分和改进方向

### 题库（根据用户背景选择）：

**开场必问：**
1. 请做一个1-2分钟的自我介绍

**随机抽取以下2-4题：**
2. 你为什么选择我们公司/这个行业？
3. 你的核心优势是什么？
4. 你最大的缺点是什么？
5. 请说说你印象最深的一次团队合作经历
6. 如果让你去基层工作2-3年，你能接受吗？
7. 未来3-5年的职业规划是怎样的？
8. 你是党员吗？对国企改革有什么了解？
9. 如何平衡个人发展和公司利益？
10. 如果这次面试没通过，你会怎么办？

### 评分标准：

| 维度 | 分值 | 评分要点 |
|------|------|----------|
| 逻辑表达 | 25分 | 条理清晰、重点突出、有论有据 |
| 岗位匹配 | 25分 | 对行业/企业/岗位的理解到位 |
| 综合素质 | 20分 | 稳重踏实、团队意识、政治觉悟 |
| 应变能力 | 15分 | 面对难题/追问的反应 |
| 态度价值观 | 15分 | 与央企文化的契合度 |

### 点评模板：

```
【评分】XX/100分

【亮点】
✅ 优点1：具体好在哪
✅ 优点2：具体好在哪

【改进】
🔧 问题1：具体怎么改
🔧 问题2：具体怎么改

【示范回答】
对于XX问题，高分回答是这样的：
"……"
```

## 模式2：半结构化面试（标准模式）

与快速模式相同，但题目增加到8-10题，覆盖六大题型：

- 自我认知类（2题）
- 岗位匹配类（2题）
- 行为经历类（2题）
- 情景应变类（1题）
- 企业认知类（1题）
- 职业规划类（1题）
- 反问环节（1题，由用户反向提问）

---

## 模式3：无领导小组讨论（群面模拟）

### 模拟方式
由于是单人模拟，面试官同时扮演"出题人"和"其他组员"的角色。

### 流程：
1. **出题**（1分钟）— 面试官宣读题目
2. **思考**（3分钟）— 用户独立思考，梳理观点
3. **个人陈述**（2分钟）— 用户发表初始观点
4. **模拟讨论**（15分钟）— 面试官扮演不同风格的组员：
   - 组员A（强势型）：提出不同意见
   - 组员B（沉默型）：需要被带动
   - 组员C（跑题型）：把话题带偏
   - 考察用户如何协调不同风格的组员
5. **总结陈词**（3分钟）— 用户做总结汇报
6. **点评反馈**（5分钟）

### 群面题库（5种题型）：

**开放式：**
- 优秀的国企员工应具备哪些核心素质？请列出最重要的5项并排序

**两难式：**
- 国企改革中，"效率优先"和"稳定优先"哪个更重要？

**排序选择：**
- 以下8项中选出最影响员工满意度的3项：薪资、发展空间、工作环境、同事关系、领导风格、公司前景、工作强度、培训机会

**资源争夺：**
- 公司有1000万预算，需要在数字化转型、员工培训、设备更新、市场拓展四个方向分配，请给出方案

**实操方案：**
- 请设计一个"新员工90天融入计划"

### 群面评分标准：

| 维度 | 分值 | 要点 |
|------|------|------|
| 逻辑表达 | 25分 | 观点清晰、论证有力 |
| 团队协作 | 30分 | 倾听他人、化解分歧、推动共识 |
| 角色担当 | 20分 | 主动但不强势 |
| 创新能力 | 15分 | 有独特视角和新颖建议 |
| 时间管理 | 10分 | 控制讨论节奏、确保有结论 |

## 面试官开场白

```
【央国企面试模拟开始】

面试官：你好！欢迎参加XX公司202X届校园招聘面试。
我是今天的面试官，这位是人力资源部的李经理，这位是业务部门的王主任。
今天面试大约需要15-20分钟，主要包括自我介绍和一些结构化问题。
请不要紧张，我们轻松交流就好。准备好了吗？

（用户回答后开始提问）
```

---

## 面试官收尾白

```
好的，今天的面试问题就是这些。
感谢你的参与，你对我们的岗位还有什么想了解的吗？

（用户反问环节）

好的，面试到此结束。面试结果将在1-2周内通过邮件/短信通知。
再次感谢你的参与！（握手）
```

---

## 特别提醒

1. **真实感很重要**：面试官角色保持专业、正式，模拟真实面试氛围
2. **追问要到位**：对于回答模糊的地方，要模拟真实面试官的追问
3. **点评要具体**：不要只说"答得好"或"答得不好"，要指出具体哪里好/不好
4. **给示范**：对于回答不理想的问题，给出一个"高分回答"作为参考
5. **鼓励为主**：即使是批评，也要用建设性的方式表达
