# 笔试刷题工具 — Quiz Generator

## 使用说明

当用户说"刷题"或"出题"，按以下规则生成题目。每次出5题，一个模块，用户答完后逐题讲解。

---

## 行测五大模块题库

### 模块1：言语理解与表达

**题型A：选词填空**
```
例题：
从"双碳"目标的提出到各项政策的落地实施，我国绿色低碳转型的步伐不断______。
A. 加快  B. 减缓  C. 停滞  D. 波动

答案：A
解析："不断"后面接正向趋势词，"加快"最符合语境。
```

**题型B：片段阅读（主旨概括）**
```
例题：
国企改革三年行动实施以来，中央企业在完善中国特色现代企业制度、推进国有经济布局优化和结构调整等方面取得显著成效。接下来需要进一步增强核心功能、提升核心竞争力。
这段文字主要说明了：
A. 国企改革已经完成
B. 国企改革取得的成效和下一步方向
C. 国企改革的效果不好
D. 国有企业将全面私有化

答案：B
解析：前半句说成效，后半句说"接下来需要"，即下一步方向。
```

**题型C：语句排序**
```
例题：将以下句子排列成连贯的段落
①从而推动国有资本做强做优做大
②通过混合所有制改革引入市场化机制
③国有企业改革正在进入深水区
④提升国有企业的经营效率和竞争力

正确排序：③②④①
解析：③提出话题→②具体措施→④直接效果→①最终目标（递进关系）
```

### 模块2：数量关系

**题型A：工程问题**
```
例题：一项工程，甲单独做需要12天，乙单独做需要18天。两人合作3天后，甲因故离开，剩下的由乙单独完成。问乙还需要多少天？
A. 8天  B. 9天  C. 10.5天  D. 12天

答案：C
解析：设总量36，甲效率3/天，乙效率2/天。
合作3天：(3+2)×3=15，剩余36-15=21
乙单独：21÷2=10.5天
```

**题型B：利润问题**
```
例题：某商品按定价的80%出售，仍能获得20%的利润。问定价时期望的利润率是多少？
A. 40%  B. 50%  C. 60%  D. 70%

答案：B
解析：设成本100，售价=成本×(1+20%)=120
售价=定价×80%，所以定价=120÷0.8=150
利润率=(150-100)/100=50%
```

### 模块3：判断推理

**题型A：图形推理**
```
例题：
给出前三个图形：○ → ◎ → ● （实心越来越满）
问第四个图形是什么？
规律：每次增加25%填充度，第四个是完全实心的●
```

**题型B：逻辑判断（削弱型）**
```
例题：
某公司认为，给员工提供免费午餐能提高工作效率，因为员工不必花时间外出就餐。
以下哪项最能削弱上述论证？
A. 员工外出就餐也是一种休息方式
B. 有免费午餐后员工反而花更多时间在餐厅聊天
C. 其他公司也有免费午餐
D. 员工普遍喜欢免费午餐

答案：B
解析：题干：免午餐→不用外出→效率高。B直接切断了"免午餐"与"效率高"的因果链。
```

**题型C：定义判断**
```
例题：
"灰犀牛事件"是指大概率且影响巨大的潜在危机，人们往往因其常见而忽视。
以下哪项属于灰犀牛事件？
A. 突如其来的大地震
B. 人工智能发展带来的就业结构变化
C. 中了彩票头奖
D. 被陨石砸中

答案：B
解析：AI带来的就业变化是大概率（可预见）且影响巨大（大量岗位被替代）的，符合"灰犀牛"定义。A是"黑天鹅"（不可预测）。
```

### 模块4：资料分析

```
例题：
2024年某央企营业收入8500亿元，同比增长8.5%；利润总额620亿元，同比增长12.3%。
2023年营业收入7900亿元，利润总额552亿元。

问题1：2024年该央企的利润率（利润/营收）约为多少？
A. 6.5%  B. 7.3%  C. 8.1%  D. 9.2%
答案：B  解析：620/8500≈7.29%，选7.3%

问题2：2024年利润率较2023年提升了多少个百分点？
A. 0.3个  B. 0.5个  C. 0.7个  D. 1.0个
答案：A
解析：2023利润率=552/7900≈6.99%，2024=7.29%，提升约0.3个百分点
```

## 出题规则

1. **每次5题**：默认从一个模块选5题，用户也可以指定混合模块
2. **难度分级**：基础（默认）→ 进阶 → 冲刺（逐步递增）
3. **参考答案**：每题给出正确答案+详细解析
4. **用户答完后**：逐题对照，标出对错，分析错因
5. **错题记录**：提醒用户把错题加入错题本

---

## 使用示例

用户说"刷题 言语理解"，则生成5道言语理解题。

用户说"来一套行测"，则从5个模块各选1题，组成一套5题小测验。

用户说"多出点"，则加量到10题。
