# 网申与简历指南

## 一、央国企简历 vs 互联网简历（核心差异）

| 维度 | 央国企偏好 | 互联网偏好 |
|------|-----------|-----------|
| **整体风格** | 稳重、规范、信息完整 | 创意、个性化、简约 |
| **政治面貌** | 非常看重（党员大加分） | 一般不关注 |
| **学生干部** | 非常加分 | 一般 |
| **获奖证书** | 详细列出（尤其国家/省级） | 挑重点 |
| **教育背景** | 985/211/双一流明确标注 | 看重能力>学校 |
| **实习经历** | 知名度+相关性+STAR量化 | 项目成果>公司名气 |
| **排版设计** | 简洁清晰，忌花哨 | 可以个性化 |
| **证件照** | 必须！（蓝底正式照） | 可有可无 |

## 二、简历七个板块详解

### 1. 个人信息
- 姓名、电话、邮箱（建议用163/126，显得正式）
- 政治面貌：党员/预备党员/团员（放在显眼位置）
- 籍贯：与意向工作城市一致的可以写
- 出生年月/年龄

### 2. 教育背景
- 格式：学校 + 专业 + 学历 + 起止时间
- 985/211/双一流学校请加括号注明
- GPA：3.5/4.0以上必写，专业课GPA更高的可以单独列出
- 主修课程：列举3-5门与岗位相关的核心课程

### 3. 实习经历（STAR法则）

每条经历格式：
```
公司名称 | 岗位 | 起止时间
- 背景/情境(S)：在XX情况下
- 任务(T)：负责XX任务
- 行动(A)：采取了XX行动
- 结果(R)：取得了XX成果（用数据量化！）
```

示例：
> **国家电网XX省公司 | 暑期实习生 | 2025.07-2025.09**
> - 参与XX供电公司迎峰度夏项目，协助完成负荷预测模型的搭建
> - 独立处理XX区域的用电数据（约5万条），将数据准确率从92%提升至98%
> - 撰写1份分析报告被部门采纳，为夏季用电调度提供数据支撑

### 4. 项目/科研经历
- 格式与实习经历一致
- 重点突出你的贡献（不是项目的成果）
- 技术岗：项目内容+技术栈+你的角色+量化成果

### 5. 校园经历
- 学生干部、社团经历（央国企非常看重组织协调能力）
- 格式：角色 + 做了什么 + 规模/成果
- 示例："学生会XX部长，组织XX活动，参与人数300+，获评校级优秀活动"

### 6. 获奖荣誉
- 按级别排序：国家级 > 省级 > 校级
- 标注获奖比例（如Top5%）
- 奖学金、优秀学生/干部、竞赛获奖最重要

### 7. 技能证书
- 必写：英语四六级（含分数）、计算机二级
- 加分项：CPA、建造师、法律职业资格、CFA、PMP
- 如实写，不要编造（背调查得出）

## 三、网申注意事项

### 准备材料（提前扫描好！）

| 材料 | 格式要求 | 备注 |
|------|----------|------|
| 蓝底证件照 | JPG，<500KB | 去专业照相馆拍，不要用手机自拍 |
| 学籍在线验证报告 | PDF | 学信网下载 |
| 成绩单 | PDF，盖章 | 教务处打印 |
| 就业推荐表 | PDF，盖章 | 学校就业中心领取 |
| 英语四六级成绩单 | PDF/JPG | |
| 获奖证书扫描件 | PDF/JPG | 分门别类整理好 |
| 身份证正反面 | JPG | |

### 网申填写技巧

1. **先在Word写好再粘贴**：避免网页超时丢失
2. **填写完整度100%**：每一项都认真填写，不空着
3. **开放性问题认真写**：如"为什么选择我们公司""自我评价"，HR会看
4. **信息一致性**：网申系统与简历内容一致，不要有矛盾
5. **申请提交前截图保存**：万一面试时被问到

### 投递策略

| 策略 | 说明 |
|------|------|
| **梯度投递** | 冲刺（10-15家）+ 匹配（15-20家）+ 保底（5-10家） |
| **节奏把控** | 每天2-3家，不要一口气全投完 |
| **记录台账** | 建立Excel记录：企业名 + 岗位 + 投递时间 + 当前状态 + 账号密码 |
| **优先官网** | 尽量走企业官方招聘网站，其次国聘网 |
| **截止前7-10天投递** | 太早可能被后来者覆盖，太晚可能系统拥堵 |

## 四、简历自检清单

请逐条检查你的简历：

- [ ] 证件照是否为蓝底正式照？
- [ ] 政治面貌是否放在显眼位置？
- [ ] 联系方式是否正确？
- [ ] 教育背景是否标注了985/211/双一流？
- [ ] 实习经历是否用了STAR法则？是否有数据量化？
- [ ] 学生干部经历是否体现？
- [ ] 获奖荣誉是否按级别排序？
- [ ] 英语四六级是否写了分数？
- [ ] 排版是否简洁干净（没有花哨模板）？
- [ ] 是否控制在1页以内？
- [ ] 是否有错别字？
- [ ] PDF格式是否命名规范（"姓名-学校-岗位.pdf"）？

## 五、简历常见错误

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 用互联网风的花哨模板 | 用简洁朴素的模板，重点突出信息 |
| 写了"期望薪资" | 央国企简历不需要写 |
| 实习经历只写了公司名 | 用STAR法则详细展开，量化成果 |
| "我负责XX工作" | "我通过XX方法，完成了XX，成果是XX" |
| 没写政治面貌 | 党员/团员一定要写 |
| 照片用生活照/自拍 | 必须用专业证件照 |
| 发了Word格式 | 必须发PDF |
| 文件名是"个人简历.pdf" | "张三-XX大学-电气工程-国家电网.pdf" |
