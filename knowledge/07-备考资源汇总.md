## 五、备考时间投入建议

| 备考周期 | 总时长建议 | 每天建议 |
|----------|-----------|----------|
| **3个月备战** | 300-400小时 | 3-4小时/天 |
| **2个月备战** | 200-300小时 | 3-5小时/天 |
| **1个月冲刺** | 100-150小时 | 3-5小时/天 |
| **在职备考** | 200小时 | 2-3小时/天（利用晚上+周末） |

### 时间分配建议

| 模块 | 占比 | 说明 |
|------|------|------|
| 行测学习+刷题 | 40% | 最重要，拉分项 |
| 专业知识复习 | 25% | 技术岗加量 |
| 申论/写作 | 15% | 每周1-2篇即可 |
| 面试练习 | 15% | 笔试通过后再集中练 |
| 时政/企业文化 | 5% | 日常积累+考前突击 |

## 六、免费 vs 付费资源

### 免费（推荐优先使用）

- 粉笔APP免费题库
- B站行测/申论课程（搜索"行测基础课"）
- 学习强国APP（时政）
- 牛客网面经
- 学校就业指导中心资源
- 国资小新公众号
- 各国企官网企业文化页

### 付费（按需选择）

- 中公/华图/粉笔系统班（1000-5000元）
- 一对一面试辅导（200-500元/次）
- 各企业历年真题资料（淘宝/闲鱼，50-200元）
- 简历修改服务（100-300元）

> ⚠️ 注意：报班不是必须的！大量上岸同学没有报任何班，靠免费资源+自律备考就够了。如果报班，建议报行测基础班即可，不要买"保过班"（智商税）。

## 七、各环节准备清单

### 暑假（7-8月）
- [ ] 拍好蓝底证件照
- [ ] 扫描所有证书、成绩单
- [ ] 写好简历初稿（2-3个版本）
- [ ] 注册国聘网账号，完善在线简历
- [ ] 开始行测基础学习
- [ ] 关注"国资小新"等公众号

### 9月投递期
- [ ] 每天浏览国聘网和企业官网
- [ ] 建立投递台账Excel
- [ ] 每天投递2-3家
- [ ] 行测刷题每天50题+
- [ ] 针对目标企业完善简历

### 10月笔试期
- [ ] 每天1套完整行测真题（计时）
- [ ] 专业课集中复习
- [ ] 突击目标企业文化知识
- [ ] 申论每周2篇

### 11-12月面试期
- [ ] 准备自我介绍（3个版本：1分钟/2分钟/3分钟）
- [ ] 半结构化20个高频问题逐个打磨
- [ ] 群面模拟至少3次
- [ ] 关注补录机会
