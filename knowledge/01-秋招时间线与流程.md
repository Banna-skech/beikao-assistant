# 央国企秋招时间线与全流程

## 一、全年时间线总览

央国企校招时间线跨越整个学年，以下是完整时间表：

```
7月   ████████████ 提前批启动（军工、通信、能源头部央企）
8月   ████████████ 暑期实习转正 + 提前批面试 + 备考黄金期
9月   ████████████████████ 秋招正式批集中爆发（全年70%岗位释放）
10月  ████████████████████ 网申密集期 + 笔试高峰期
11月  ████████████████ 面试高峰期 + 国家电网统招发布
```

## 二、秋招三阶段详解

### 📌 提前批（7月-8月）

| 维度 | 说明 |
|------|------|
| **代表企业** | 国家电网、中石油、航天科技、航天科工、中国电子科技 |
| **特点** | 免笔试/笔试简化，直通面试，部分企业走"提前批+正式批"双通道 |
| **面向群体** | 985/211院校、特定专业（电气、石油、航天等） |
| **录取率** | 国家电网提前批录取率较正式批高约30% |
| **策略** | **有资格一定要冲！** 提前批失败不影响正式批投递 |

### 📌 正式秋招（9月-11月）— 黄金投递期

全年90%的央国企岗位在此阶段释放：

- **国有六大行**：网申集中在8月底-10月中旬，笔试10月中下旬
- **三桶油**（中石油/中石化/中海油）：网申9月中下旬起
- **三大运营商**（移动/联通/电信）：网申8月下旬起，笔试10月
- **五大发电集团**：网申9月起
- **中建/中铁/中交**：网申9月起陆续发布
- **国家电网**：一批11月中下旬网申，一批12月初笔试（全国统考）
- **中国烟草**：各省公司时间不一，多数11月起
- **铁路局**：18家铁路局集中在下半年

### 📌 补录批（12月-次年3月）

- 秋招未招满的岗位补录
- 部分企业仅参加春招（如中储粮、部分地方国企）
- 国家电网第二批：3月网申，4月笔试
- 竞争压力明显小于秋招，但岗位数量也少

## 三、招聘全流程（6大环节）

### 第1关：网申 → 淘汰率约70%

```
投递简历 → 机器筛选（学历/专业/年龄硬性条件）
         → 人工筛选（实习经历/证书/证件照等软实力）
         → 笔试通知（通常网申截止后1-3周）
```

**关键时间节点**：
- 网申周期通常15-30天
- 建议截止前7-10天完成投递（避免系统拥堵）
- 热门岗位可能"滚动筛选、招满即止"

### 第2关：笔试

| 笔试形式 | 说明 |
|----------|------|
| **线上机考** | 双摄像头监控，AI监考（银行、部分央企常用） |
| **线下机考** | 统一考点（国家电网全国统考、三桶油、国有六大行） |
| **线下纸笔** | 少数传统企业 |

**笔试后通知面试**：通常1-4周

### 第3关：面试（2-3轮）

```
第一轮：无领导小组讨论（群面，6-10人）
         ↓
第二轮：半结构化面试（单面，2-4位面试官）
         ↓
第三轮：终面/领导面（部分企业有，高层参与）
```

### 第4关：体检与背景调查

- **体检标准**：参照公务员体检标准
- **差额体检**：按总成绩排名1:1.2-1:1.5组织体检，排名靠后者可能被刷
- **背景调查**：核查学历真实性、犯罪记录、征信等
- ⚠️ **简历切勿造假！国企背调非常严格**

### 第5关：签约

- 发放Offer → 签订三方协议 → 明确入职时间
- 重点核对：**违约金**（军工类可达5万元）、**落户政策**、**编制类型**
- 避免口头承诺，一切以书面为准

## 四、各阶段备考策略

| 阶段 | 核心任务 | 每日时间建议 |
|------|----------|-------------|
| **7-8月（暑期）** | 打磨简历 + 行测基础学习 + 关注提前批 | 4-6小时 |
| **9月（投递月）** | 精准投递（每天2-3家）+ 行测刷题 + 申论积累 | 投递1h + 学习4h |
| **10月（笔试月）** | 行测冲刺 + 专业课复习 + 企业知识突击 | 5-6小时 |
| **11-12月（面试月）** | 半结构化练习 + 群面模拟 + 持续投递 | 根据面试时间灵活调整 |
| **次年1-3月** | 查漏补缺 + 春招补录 + 签约准备 | 根据实际情况 |

## 五、关键提醒

> ⚠️ **秋招岗位数量远多于春招**，部分企业（如国家电网一批）仅在秋招收人，切勿抱着"等春招再说"的心态！
> ⚠️ **央国企流程非常慢**，从网申到Offer可能长达4-5个月，保持耐心，不要焦虑。
> ⚠️ **同时准备考研/考公的同学**：可以先拿一个央国企Offer保底，每年都有大量"考公失败转央国企"的成功案例。
