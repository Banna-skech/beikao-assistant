# 央国企笔试备考指南

## 一、笔试科目概览

央国企笔试通常包含六大模块，不同企业组合不同：

| 模块 | 出现频率 | 分值占比 | 难度 |
|------|----------|----------|------|
| **行测（EPI）** | ⭐⭐⭐⭐⭐ 几乎必考 | 40%-70% | 低于公务员 |
| **申论/写作** | ⭐⭐⭐ 部分企业 | 20%-30% | 低于公务员 |
| **专业知识** | ⭐⭐⭐⭐ 技术岗必考 | 30%-60% | 视岗位而定 |
| **公共基础知识** | ⭐⭐⭐⭐ 高频 | 5%-15% | 记忆为主 |
| **企业文化** | ⭐⭐⭐⭐ 高频 | 5-10分 | 送分题 |
| **英语** | ⭐⭐ 银行/外贸 | 10%-20% | CET4-CET6 |

## 二、行测 — 五大题型详解

### 1. 言语理解与表达

| 子题型 | 考查点 | 解题技巧 |
|--------|--------|----------|
| 选词填空 | 词语辨析、语境分析 | 找前后文逻辑关系（转折/递进/并列），排除法 |
| 片段阅读 | 主旨概括、细节判断 | 重点关注首尾句、转折词、观点词 |
| 语句排序 | 逻辑连贯性 | 先定首句（排除有指代不明的），再找捆绑对 |
| 病句修改 | 语法规范 | 常见语病：搭配不当、成分残缺、语序不当 |

**备考建议**：每天20题，重在积累语感和常见错误类型。

### 2. 数量关系

| 子题型 | 常考考点 | 解题技巧 |
|--------|----------|----------|
| 数学运算 | 工程问题、行程问题、利润问题、排列组合 | 赋值法、方程法、代入排除 |
| 数字推理 | 等差数列、等比数列、幂次数列 | 看相邻项差/商的变化规律 |

**备考建议**：掌握10种核心题型解法即可，不要花太多时间在偏难怪题上。央国企的数量关系比公务员简单。

### 3. 判断推理

| 子题型 | 考查点 | 解题技巧 |
|--------|--------|----------|
| 图形推理 | 位置、样式、属性、数量规律 | 对称性 > 叠加 > 数量（点线面角） |
| 定义判断 | 关键信息提取与匹配 | 圈关键词，选项逐一对照 |
| 类比推理 | 词项间逻辑关系 | 种属/组成/功能/因果/近义反义 |
| 逻辑判断 | 论证推理、真假推理 | 抓论点论据，削弱加强看论证链 |

**备考建议**：判断推理是最容易提分的模块，图形推理多刷题建立规律敏感度。

### 4. 资料分析

| 考查点 | 核心公式 | 解题技巧 |
|--------|----------|----------|
| 增长率 | (现期-基期)/基期 | 估算！不需要精确计算 |
| 比重 | 部分/整体 | 看选项差距，差距大就估算 |
| 倍数 | A/B | 注意"是几倍"vs"多几倍" |
| 平均值 | 总数/个数 | 注意单位换算 |

**备考建议**：资料分析是行测中正确率最高的模块，熟练掌握速算技巧后可达90%+正确率。

### 5. 常识判断

| 类别 | 重点内容 |
|------|----------|
| **时政** | 近一年国内重大政策、会议、讲话（占60%以上） |
| **法律** | 宪法、民法典、公务员法、公司法基础 |
| **科技** | 航天成就、重大科技突破 |
| **人文** | 中国传统历史文化常识 |
| **经济** | 基本经济概念、宏观经济政策 |

## 三、申论/写作

### 题型

1. **归纳概括**（200-300字）：提炼材料核心观点
2. **提出对策**（300-500字）：针对问题给出解决方案（分政府/企业/个人层面）
3. **综合写作**（800-1000字）：围绕主题论述

### 2026届热点话题预测

| 热点主题 | 备考方向 |
|----------|----------|
| 新质生产力 | 科技创新驱动、现代化产业体系 |
| 数字中国 | 数字化转型、数据要素、人工智能+ |
| 双碳目标 | 绿色低碳转型、新能源发展 |
| 国企改革深化提升 | 增强核心功能、提升核心竞争力 |
| 区域协调发展 | 西部大开发、东北振兴、长三角一体化 |
| 银发经济 | 人口老龄化应对、养老产业发展 |
| 乡村振兴 | 农业农村现代化 |
| 一带一路 | 高水平对外开放 |

### 写作框架（万能模板）

```
【开头】政策背景（引用/数据）+ 提出问题 + 亮明观点
  ↓
【分析段1】原因分析/现状分析（分2-3个角度）
  ↓
【分析段2】影响分析/必要性分析
  ↓
【对策段1】政府/企业层面（宏观措施）
  ↓
【对策段2】个人/社会层面（微观措施）
  ↓
【结尾】回扣主题 + 展望未来 + 升华
```

## 四、各企业差异化备考

### 国家电网
- **专业占比70%**（电工类：电路、电力系统分析、继电保护、高电压、发电厂电气）
- 行测+企业文化+时政 占30%
- 全国统一机考（165题/180分钟）

### 国有六大行
- 行测+英语+综合知识（金融、经济、会计、法律、计算机）
- 英语难度约CET4-CET6
- 线上机考为主

### 三桶油
- 行测为主 + 专业知识选考
- 中石油考"思想素质"（类似行测+企业文化）
- 部分岗位有英语测试

### 三大运营商
- 行测为主 + 企业文化 + 行业常识
- 计算机/通信岗加考专业知识
- 笔试相对简单，面试权重更大

### 中国烟草
- 行测+申论为主
- 各省自主命题，差异较大
- 竞争最激烈（待遇最好）

## 五、备考三阶段计划

### 阶段一：基础攻坚（第1-4周）

| 每日任务 | 时长 |
|----------|------|
| 行测基础课学习（按模块顺序） | 2-3小时 |
| 配套练习30题 | 1小时 |
| 时政积累（人民日报APP/学习强国） | 30分钟 |
| 专业知识点梳理 | 1小时 |

### 阶段二：刷题强化（第5-8周）

| 每日任务 | 时长 |
|----------|------|
| 行测刷题50-100题 | 2-3小时 |
| 错题整理与分析 | 30分钟 |
| 专业课题库30题 | 1小时 |
| 申论每周2篇 | 1-2小时/篇 |

### 阶段三：模拟冲刺（第9-12周）

| 每日任务 | 时长 |
|----------|------|
| 完整真题1套（严格计时） | 2-3小时 |
| 真题解析+错题整理 | 1小时 |
| 企业文化突击（考前3天） | 30分钟 |
| 时政热点过一遍 | 30分钟 |

## 七、笔试避坑指南

1. ❌ **不要盲目刷题**：先确定目标企业的考纲和题型分布，有的放矢
2. ❌ **不要忽视企业文化和常识**：这5-10分是送分题，考前突击就能拿
3. ❌ **不要轻视时间管理**：行测最大的难点是时间不够，平时练习必须计时
4. ❌ **不要只练一种题型**：行测五大模块都要覆盖，但优先练提分快的（言语+判断+资料分析）
5. ✅ **行测正确率目标**：言语80% + 判断85% + 资料90% + 数量60% + 常识60%
